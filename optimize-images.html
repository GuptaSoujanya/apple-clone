Image Optimization Recommendations

Current Image Sizes:

  • dickinson-apple-tv.png: 156KB

Optimization Steps:

  1. Convert to WebP format: Use tools like cwebp to convert PNG/JPG to WebP (typically 25-35% smaller)
  2. Resize images: The iPad Air image should be resized to actual display dimensions
  3. Use responsive images: Implement srcset for different screen sizes
  4. Progressive JPEG: For remaining JPEG images, use progressive encoding

Commands for optimization (when tools are available):

# Convert to WebP (requires cwebp)
cwebp -q 80 img/ipad-air.png -o img/ipad-air.webp
cwebp -q 85 img/macbook-air.png -o img/macbook-air.webp

# Resize large images (requires ImageMagick)
convert img/ipad-air.png -resize 800x600 img/ipad-air-optimized.png

# Create responsive versions
convert img/ipad-air.png -resize 400x300 img/ipad-air-small.png
convert img/ipad-air.png -resize 800x600 img/ipad-air-medium.png

HTML Pattern for optimized images:

<picture>
    <source srcset="img/ipad-air.webp" type="image/webp">
    <source srcset="img/ipad-air.png" type="image/png">
    <img src="img/ipad-air.png" alt="iPad Air" loading="lazy">
</picture>
